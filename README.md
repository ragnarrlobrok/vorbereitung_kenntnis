# Lernportal Kenntnisprüfung

Digitale Lernbegleitung für eine Teilnehmerin mit Terminen, Prüfungsabläufen,
einem Übungsfall und einer lokalen Pflegeplanungsübung.

## Auf Netlify veröffentlichen

Das Repository in Netlify importieren. Kein Build-Befehl erforderlich.
Veröffentlichungsverzeichnis: `.` (Projektwurzel).
Die Datei `netlify.toml` enthält diese Einstellung bereits.

## Lokal öffnen

`index.html` im Browser öffnen oder diesen Ordner mit einem lokalen Webserver
bereitstellen. Alle benötigten Ressourcen liegen im Repository.

## Enthaltene Unterlagen

- Übungsfall als Teilnehmendenfassung ohne Lösungen
- Leeres Arbeitsblatt zur Pflegeanamnese und Pflegeplanung

Die separate Herzinfarkt-Prüfung und Erwartungshorizonte bleiben außerhalb
dieses Repositories.

Notizen und Checklisten bleiben im Browser und werden nicht automatisch
übermittelt. Export und Import einer lokalen Sicherung sind möglich.
Für Übungen fiktive oder anonymisierte Angaben verwenden.
